# PawLink · 宠伴桌面

本地优先的虚拟宠物桌面应用原型。数据保存在浏览器 `localStorage`；开启摄像头时，画面只用于本地预览，原型不存储或上传视频。

## 运行

直接用浏览器打开 `index.html` 即可浏览界面。部分浏览器会限制从本地文件地址请求摄像头；若摄像头无法启用，请用任意本地静态服务器打开目录（例如 VS Code 的 Live Server），并允许摄像头权限。

## 当前实现

- 可编辑的宠物档案与本地存储
- CSS 生成的虚拟猫咪形象和互动动画
- 可添加、完成、恢复的照护日程
- 摄像头本地预览及“宠物入画”交互演示
- 隐私优先文案与状态界面
