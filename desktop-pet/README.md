# PawLink Desktop Pet

透明、置顶、可互动的 Windows 桌宠。默认使用随项目提供的 Kenney Cube Pets CC0 免费猫咪 GLB；无需 API Key、无需云端服务，角色和配置均在本机运行。

## 安装与启动

1. 安装完整的 [Node.js LTS](https://nodejs.org/)；请在终端确认 `node --version` 和 `npm --version` 都有输出。
2. 在此目录执行：

   ```powershell
   npm install
   npm start
   ```

3. 点击桌宠右下角的 `⚙`，填写宠物档案。

## 桌宠控制

- `♡`：互动；
- `⚙`：打开设置；
- `⌁`：切换鼠标穿透；
- `Alt+Shift+P`：全局切换鼠标穿透。
- `Alt+Shift+O`：无论桌宠是否可点，直接打开设置窗口。
- 滚轮或 `Shift + 左键拖动`：旋转 3D 宠物；桌宠也会自动缓慢旋转。

## 实现说明

- 预设角色：猫、狗、兔子、狐狸、熊猫、鹦鹉以及卡通人偶。
- 渲染管线：ACES Filmic 色调映射、程序化环境光、主光、补光与接触阴影。
- 角色按包围盒自适应缩放并统一落地，保证不同模型观感一致。
- 支持本地 Ollama 对话。Meshy API Key 使用系统安全存储保存在应用数据目录，不会写入仓库。
